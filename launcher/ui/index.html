Custom server

Point the client at any Lost City server — as a bridge, or straight up.
A bridge serves the page on localhost and tunnels everything — http and the game socket — to that address. "Serve my build" swaps in the client bundle built for the selected install, so your mods work on someone else's world. Servers that pin allowedOrigin can refuse the bridged socket; direct open always works.
